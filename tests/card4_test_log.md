
# 카드 4 — 템플릿 관리 테스트 기록

- 검사 날짜: 2026-10-16
- 검사 환경: Chrome / Live Server
- 저장 방식: localStorage
- 검사 대상: 템플릿 CRUD 기능

## 1. 구현 기능

- Create: 현재 편집 설정을 새 템플릿으로 저장
- Read: 저장한 템플릿의 설정을 불러오기
- Update: 기존 템플릿의 이름과 설정을 수정
- Delete: 선택한 템플릿을 확인 후 삭제
- Persistence: 새로고침 후에도 저장 데이터 유지

※ 현재 템플릿에는 문구, 배경, 화면비, 이미지 배치 설정을
저장하며 이미지 파일 자체는 저장하지 않는다.

## 5. 이번 카드에서 배운 점

- CRUD는 생성(Create), 조회(Read), 수정(Update), 삭제(Delete)를 의미한다.
- localStorage는 브라우저에 문자열 형태로 데이터를 저장한다.
- JSON.stringify()와 JSON.parse()로 객체 데이터를 저장하고 복원할 수 있다.
- find()는 조건에 맞는 항목을 찾을 때 사용한다.
- filter()는 조건에 맞는 항목들로 새로운 배열을 만들 때 사용한다.
- 템플릿 이름과 별도로 고유 ID를 사용하면 항목을 정확하게 구분할 수 있다.
- CSS는 작성 순서뿐 아니라 선택자 우선순위에 따라 적용 결과가 달라진다.
